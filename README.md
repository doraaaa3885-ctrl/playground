# 一起玩，会发生什么？

一座由康威生命游戏（Conway's Game of Life）驱动的互动儿童游乐场。采用灰白纸感场景、红色游乐设施与铅笔质感人物。

## 本地运行

需要安装 Python 3；运行测试还需要 Node.js。无需安装项目依赖。

```powershell
cd E:\AAAvibe\playground
npm start
```

也可以直接运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

浏览器访问 http://127.0.0.1:8765/ 。由于网页使用 JavaScript 模块，请通过本地服务器运行。

## 交互

- 滚轮或双指缩放，拖动平移；缩放和平移不会重置演化或生成新细胞。
- 拉近观察人物与对白，点击孩子暂停并进入观察模式。
- 播放、暂停、逐轮演化、调速、重置、清空。
- 暂停后添加或移除孩子，放置方块静物、闪烁器或滑翔机。
- 开启规则网格，选中位置查看周围八格人数，以及上一轮到本轮的计算依据。

## 计算规则

全场使用同一张 384 × 384 的有限网格，遵循 B3/S23：空格有三个活邻居时新生；活细胞有两个或三个活邻居时保留。所有位置使用上一轮状态同步计算，最外侧边界不首尾相接。

初始分布包含 11,838 名孩子。人物动作、外观、对白和镜头不参与计算。该场景是艺术表达，不是儿童行为或心理预测模型。

## 验证

```powershell
npm test
```

测试覆盖静物、振荡器、滑翔机、有限边界、同步更新、全部 512 种局部状态、初始分布和中央广场以外的演化。

## 文件

- `dist/index.html`：网页结构。
- `dist/app.js`：镜头、界面、对白与交互。
- `dist/life.js`：基础生命游戏规则。
- `dist/simulation.js`：全场网格与初始分布。
- `dist/world.js`：场景、人物绘制。
- `dist/assets/`：人物素材。
- `tests.mjs`、`tests-world.mjs`：规则与场景测试。
